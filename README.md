# 供应链风险雷达

把公开新闻归并为外部风险事件，并关联可能受影响的供应链线路。

修改 `public/` 下的页面、样式和前端脚本后，刷新浏览器即可看到更新。修改后端代码或线路数据仍需重启服务。

在项目目录运行 `npm start`（Node.js 22.18+），打开 http://127.0.0.1:4179。默认显示虚构样例。切到「实时数据」后，服务直接读取 WorldMonitor 新闻目录里选出的 17 个公开 RSS/Atom（综合、地区、经贸、航运、官方公告；见 `data/news-sources.json`），保留媒体、标题、摘要、链接和发布时间。解析、字符集、日期和体积上限沿用 WorldMonitor 新闻摘要的实现。每个源最多每 5 分钟拉取一次，并用 ETag/Last-Modified 条件请求；某个源失败时保留其上次结果。无需订阅或 API 密钥，只需 Node.js 和可访问媒体 RSS 的网络。

如需综合信号和预测，参照 WorldMonitor 仓库的 `SELF_HOSTING.md` 启动自己的实例并运行相应数据任务。启动服务 时设置 `WM_BASE_URL` 为自建实例的地址；如该实例设置了本地访问密钥，再设 `WM_API_KEY`。服务会从该实例读取新闻摘要、综合信号和预测。各来源单独显示状态。

页面右上角的「模型配置」可保存多套 OpenAI 兼容配置，每套独立设置 Base URL、API Key 和 Model ID。在面板中选择并启用配置后，右上角会显示当前模型。默认地址为 `https://api.openai.com/v1`。配置保存在本机 `var/model-settings.json`，接口不会把 API Key 发回浏览器。仍可用 `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL` 和 `DEEPSEEK_BASE_URL` 提供初始配置。模型只写事件层面的简体中文标题和最新进展，覆盖全部实时新闻事件；报道本身保持原文，可用页面的「翻译成中文」（浏览器内置翻译）阅读。调用在后台进行，接口不等待模型；页面在仍有事件待处理时会自动重读几次。新事件发送首篇和最近 3 篇报道；之后只发送尚未读过的新报道，并改用只要求输出进展的提示词。报道以紧凑的单行文本发送，不带网址；摘要只是重复标题时省略。标题须引用首篇原文，进展须引用对应报道原文并给出不晚于发稿时间的发生日期（可只到日），否则不采用。结果随事件保存在事件库的 `presentation` 字段，重启或切换模型不会重复调用；同一批报道最多尝试 2 次，之后保留原文标题，直到有新报道。服务商或网络出错时整体退避（最长 30 分钟）。服务日志记录每次调用的 token 用量和缓存命中。

可用 `PORT` 更改本机监听端口。页面支持浅色、深色、跟随系统，能筛选并导出 JSON。`GET /api/feed?mode=sample|live` 返回事件（含其全部记录）及来源状态，来源只给状态和记录数；`raw` 保留接入层原始字段。

默认载入仓库内的 `data/nodes.json` 和 `data/lanes.json`。复制或克隆本仓库即可运行，不需要父目录或另一个 WorldMonitor 仓库。卡片按明确的事件节点或报道提及地点查询关联线路。可用 `RISK_NETWORK_DATA_DIR` 指定另一份兼容的节点及线路目录，用 `GEOGRAPHY_CONFIG_PATH` 指定地理区域/坐标覆盖文件，用 `NEWS_SOURCES_PATH` 指定自定义新闻源清单。

实时新闻先筛出航道安全、运输运行、经贸政策、地缘安全、灾害、市场变化和设施事故。新闻归并使用 WorldMonitor 的标题聚类，再按 48 小时窗口切分。媒体同源和转载识别、新闻关键词分类、文章网址去重（忽略跟踪参数）也复用 WorldMonitor。评论在匹配唯一事件时以背景分析附上；不参与线路匹配。卡片保留来源链接，归并按每次拉取的快照计算。

事件卡标题下显示与导出 JSON 一致的事件 ID。实时归并以本次拉取的新闻为准；事件卡 ID 为独立的短标识，报道网址在来源字段。实时事件首次出现时登记 ID；后续归入同一事件的报道沿用该 ID。

页面记住上次选择的数据模式。已加载过实时结果的标签页刷新时，先展示上次结果，再后台更新。刷新失败时保留已有卡片，状态栏显示上次更新时间。

实时事件库默认保存在 `var/events.json`，不纳入 Git。迁移部署时把该文件一起迁移，或用 `EVENT_STORE_PATH` 指向持久化路径。每次事件变化递增 `revision`；`GET /api/events/:id` 可以读取已登记事件及其累计报道，即使它已从当前 RSS 批次退出。事件库供单个服务进程使用。

复用模块及上游版本见 `vendor/worldmonitor/README.md`。本项目另外保留与供应风险有关的选题筛选、线路映射和已发出事件 ID 的持久化。

首页采用“大区 → 地点”两级地理分组与常驻地图双向联动：默认按供应链地理走廊顺序排列大区，大区内地点严格按自西向东经度排序并展示空间走廊序列；地图按真实经纬度标注地点节点与自西向东连线，聚焦大区时自动缩放视口，支持列表与地图间的悬停高亮和点击定位。展示位置来自事件锚点、来源提供的地区或 WorldMonitor Geo Hubs 的标题匹配，与线路匹配独立；未落图事件仍在底部“地点待确认”分组中查看。底图由 WorldMonitor 同一上游版本的 `public/data/countries.geojson` 直接提供。
