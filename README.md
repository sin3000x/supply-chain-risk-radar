# 外部事件情报 Demo

独立本地仓库。在此目录运行 `npm start`（Node.js 22+），打开 http://127.0.0.1:4179。无需安装依赖。默认显示虚构样例；切换到实时接口后，服务端并行读取 WorldMonitor 的新闻摘要、综合信号和预测。各源分别显示状态，实时模式发生错误时保留错误状态。

可选环境变量：`PORT`、`WM_BASE_URL`（默认 https://www.worldmonitor.app）、`WM_API_KEY`（仅服务端使用，如有需要可按自用密钥启动）。

`GET /api/feed?mode=sample|live` 返回三类记录和各来源状态。页面可筛选并导出 JSON。公共结构包括类型、上游 ID、时间及其含义、来源、证据和预测字段；`raw` 保留原始字段。新闻按文章 URL 去重。新闻、信号、预测分别保留，跨源归并为事件时间线可在此结构上继续扩展。
