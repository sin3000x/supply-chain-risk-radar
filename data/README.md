# 默认网络快照

`nodes.json` 和 `lanes.json` 来自 risk_network 的参考线路数据。包含 199 个节点、3 个起点、26 个目的地和 78 条线路；沿途路径为参考方案。服务在启动时读取这两份文件，不需要运行造数脚本。

更新默认快照时请成对替换两个文件。若只为当前部署换数据，设置 `RISK_NETWORK_DATA_DIR` 指向含同名文件的目录。

事件地点使用当前运输网络的节点，以及 `geo-hubs.json` 中的地理节点。地理节点可通过 `networkId` 指向运输节点。大区名称、别名和区域归属在 `geography.json` 中维护。自定义运输节点可提供 `region`，填写大区 ID、名称或别名。
