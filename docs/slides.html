从盘口到事件卡

  1. Gamma API 筛选活跃盘口 0.02 ≤ pYES ≤ 0.98　∧　V ≥ 25k
    (关键词 ∨ 地理节点) → 按 V 取 Top-20
  2. 候选事件准入门槛（按盘口是否命中节点分流） 记 X∩ = X盘口 ∩ X事件（共享集，X ∈ {N, H, W}）
    若 N盘口 ≠ ∅（有地理锚点）|N∩| ≥ 1　∧　|W∩| ≥ 1
    若 N盘口 = ∅（无地理锚点）|H∩| ≥ 1　∧　|W∩|/|W盘口| ≥ 0.4
    ∧　(|W∩| ≥ 3 ∨ 2 词含领域词)
  3. 通过门槛者计算匹配分 S，取 argmax
    ×10共享运输节点 或 ×3共享地缘枢纽（兜底） ＋ ×3共享词数 ＋ 5航线相关时加分
V 盘口成交量（美元） N 运输节点（港口/海峡） H 地缘枢纽（国家/首都，无节点时兜底） W 关键词集
